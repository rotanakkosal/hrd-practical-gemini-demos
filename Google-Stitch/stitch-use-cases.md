# Google Stitch Use Cases

A prompt library for generating UI designs with Google Stitch, from class project mockups to complete design systems.

---

**Class project mockup:**

```text
Design me the main screens for a student attendance tracker app — login, dashboard showing today's classes, attendance marking page, and weekly report view. Keep it clean and academic-looking.
```

**Portfolio site variations:**

```text
Design me three different personal portfolio site layouts for a full-stack developer student — one minimal, one bold and colorful, one editorial magazine style.
```

**Complete auth flow:**

```text
Design me a complete auth flow for a SaaS app — signup, login, forgot password, password reset, email verification, and account locked screens. Keep them visually consistent.
```

**Dashboard variations:**

```text
Design me three different dashboard layouts for a personal finance app — a card-heavy version, a chart-heavy version, and a minimalist text-heavy version. Show the same data in all three.
```

**Form design comparison:**

```text
Design me the same checkout form in three styles — a single page with all fields visible, a multi-step wizard with progress bar, and accordion sections that expand one at a time.
```

**Mobile vs web responsive:**

```text
Design me the same e-commerce product page in two versions — a desktop layout with sidebar and large hero image, and a mobile layout with bottom sticky CTA. Show how the same content reshuffles.
```

**Onboarding flow:**

```text
Design me a 4-screen onboarding flow for a new productivity app — welcome screen, feature highlight one, feature highlight two, and a personalization step where users pick their goals. Include a progress indicator and a skip button.
```

**Empty states and loading states:**

```text
Design me empty states and loading states for a task management app — empty inbox, empty project list, loading skeletons, error state with retry button, and a successful action confirmation. Keep the tone friendly.
```

**Wireframe to polished design:**

```text
Here's a rough wireframe sketch of my class project landing page (uploaded). Polish it into a production-ready design with consistent typography, colors, and spacing.
```

**Design system explorer:**

```text
Generate me a complete design system for a fintech app — color palette, typography scale, button states, form inputs, cards, and icons. Show them all on one reference page.
```
