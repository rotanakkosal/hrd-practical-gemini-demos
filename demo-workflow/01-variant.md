# 01 — Variant Prompts

Tool: [variant.com](https://variant.com)

---

## ⭐ Recommended: Long prompt with brand references

```
Desktop web app called Spendly — a personal expense tracker designed for a full browser window (1440px wide). Left sidebar navigation, top bar with month picker. Main dashboard is a grid layout: large total-spent card, category breakdown donut chart, recent transactions table, and budget progress bars all visible at once. Other screens: a full transactions table with sortable columns and filters, a reports page with detailed charts, and a budgets management page. Calm, data-dense, trustworthy. Should feel like a tool a power user opens daily, not a mobile app stretched wide. Modern desktop SaaS aesthetic — think Linear, Notion, or Stripe Dashboard rather than a banking website.
```

Other brand references we can swap in: `Vercel Dashboard`, `Raycast`, `Arc Browser`, `Things 3`, `Cron Calendar`, `Height`, `Pitch`.

---

## Alternative: Short prompt for exploration

Produces **many diverse variations** (no research mode). Best when you don't yet know what you want.

```
Desktop personal expense tracker. Shows where my money goes each month and tracks budgets. Calm, modern, data-focused.
```
